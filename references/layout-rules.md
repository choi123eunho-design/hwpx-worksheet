# 레이아웃 규칙 — 빈 문단 간격 계산법

## 단위
- HWPUNIT = 1/7200 inch. **1mm ≈ 283.46 hwpunit**. A4 = 59500 × 84100.
- 페이지 여백 (skeleton 기준): top=0, header=6200 → **본문 흐름 시작 = 페이지 상단 21.9mm**.

## 빈 문단 1개의 높이 (실측 캘리브레이션 값)
- 문제 페이지 빈 문단 (paraPr 24, 100%, charPr 8): **≈ 4.13mm**
- 개념 페이지 빈 문단 (paraPr 21, 100%, charPr 8): **≈ 3.34mm**
- 배경 이미지 문단(paraPr 33)도 한 줄(≈ 위와 동일)을 차지함 — 계산에 포함할 것.

## 표준 위치 (사용자 승인 완료 값, 페이지 상단 기준)
| 요소 | 목표 위치 |
|---|---|
| 개념 본문 시작 (제목만 있는 페이지) | ≈ 47mm → 배경문단 + 빈 문단(21) **4개** |
| 개념 본문 시작 (부제목 있는 페이지) | ≈ 56mm → 배경문단 + 빈 문단(21) **6개** + 빈 문단(22) 2개 |
| 문제1 시작 | ≈ 42mm → 배경문단 + 빈 문단(24) **4개** |
| 문제2 시작 | ≈ 152mm (전 페이지 통일) |

문제2 위치는 문제1 내용 높이에 따라 달라지므로 아래처럼 계산한다:

```
필요 빈 문단 수 = round( (152mm − 문제1 끝 y) / 4.13mm )
문제1 내용 높이 어림: 본문 한 줄 ≈ 4.2mm(줄간격 100%), 표 행 ≈ 7.8mm(높이 2200),
독립 수식 문단 ≈ 6~8mm, 선택지 문단 ≈ 4.5mm, placeholder 문단 ≈ 4.5mm
```

계산이 애매하면 보수적으로 넣고, 사용자가 인쇄 PDF를 주면 아래 실측법으로 보정.

## 인쇄 PDF 실측 보정법 (검증된 루틴)
사용자가 한글에서 내보낸 PDF를 주면:
```python
# 100dpi 렌더 기준 1px = 0.254mm (A4 = 827×1169px)
# pdftoppm -png -r 100 인쇄본.pdf orig/p
# 각 페이지에서 어두운 픽셀 행을 스캔해 텍스트 블록의 시작 y를 찾는다
import numpy as np; from PIL import Image
im = np.array(Image.open('orig/p-09.png').convert('L'))
dark = (im[:,140:780] < 110).sum(axis=1)   # x 140~780: 왼쪽 장식선 제외
# dark[y] >= 3 이 3행 이상 연속되는 첫 지점 = 텍스트 블록 시작
```
측정값과 목표값의 차이를 빈 문단 높이로 나눠 반올림 → 그 개수만큼 추가/삭제.
이 방법은 실제로 개념 72mm→48mm, 문제2 132~183mm→152mm 통일에 사용됨.

## 페이지 넘침 주의
본문 가용 높이 ≈ 270mm. (마지막 내용 y + 뒤따르는 빈 문단)이 이를 넘으면
내용이 다음 페이지로 밀려 **페이지 수가 바뀌는 대형 사고**. 빈 문단을 추가할 때는
페이지 끝 여유를 반드시 확인하고, 말미의 여분 빈 문단은 1~2개로 유지.

## 표 크기 규칙
- 표준정규분포표: 2열 — z열 4406, 값열 9593 / 행 높이 2200 / 4~6행.
- 넓은 데이터 표(성적표 등): 첫 열 7900, 나머지 균등 분할, 표 전체 폭 ≤ 46000
  (본문 폭 = 59500 − 1600 − 3200 − 좌우 들여쓰기).
- 셀 텍스트가 열 폭보다 길어질 것 같으면 폭을 먼저 늘린다. 셀 줄바꿈 금지.
