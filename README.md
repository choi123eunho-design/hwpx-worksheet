# hwpx-worksheet

양식(디자인) PDF와 넣을 내용(개념 설명, 문제, 표, 수식)을 받아 **한글 HWPX 파일**로 조판해 주는 Claude 스킬입니다.

## 할 수 있는 일
- 양식 PDF를 배경으로 깔고 개념·문제·표·수식을 얹어 학습지/프린트 제작
- 수학 수식은 HWP 수식 스크립트로 입력
- 글꼴·크기·색·굵기 지정 반영, 기존 hwpx 파일과 같은 서식으로 재현

## 폴더 구성
- `SKILL.md` — 스킬 본문(작업 순서와 규칙)
- `scripts/` — 패키징·검증·서식 분석/적용 파이썬 스크립트
- `references/` — 수식 문법, 글꼴, 글자 스타일 참고 자료
- `assets/skeleton/` — HWPX 기본 골격과 예제 섹션

## 사용 방법
이 폴더를 zip으로 받아 Claude의 **설정 → 기능(스킬)** 에서 업로드하면 됩니다.
